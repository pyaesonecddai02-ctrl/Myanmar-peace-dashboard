# Myanmar Peace Process Intelligence Platform (မြန်မာ့ငြိမ်းချမ်းရေးနှင့် ပဋိပက္ခ စောင့်ကြည့်လေ့လာရေး ပလက်ဖောင်း)

မြန်မာနိုင်ငံ၏ ငြိမ်းချမ်းရေးလုပ်ငန်းစဉ် (Peace Process)၊ တစ်နိုင်ငံလုံး ပစ်ခတ်တိုက်ခိုက်မှု ရပ်စဲရေး သဘောတူစာချုပ် (NCA)၊ တိုင်းရင်းသားလက်နက်ကိုင် အဖွဲ့အစည်းများ (EAOs) ၏ နိုင်ငံရေး/စစ်ဘက်ရပ်တည်ချက်များ၊ ၁၀၂၇ စစ်ဆင်ရေးနောက်ပိုင်း မြို့နယ်များအလိုက် နယ်မြေစိုးမိုးမှုနှင့် ငြိမ်းချမ်းရေးဆွေးနွေးပွဲများ (ဟိုင်ဂင်ဆွေးနွေးပွဲများ) ကို War-Room စစ်ရေးထောက်လှမ်းရေး Dashboard ပုံစံဖြင့် တည်ဆောက်ထားသော **Interactive Web App & Geopolitical Intelligence Dashboard** ဖြစ်ပါသည်။

---

## 🌟 အဓိက ပါဝင်သော ကဏ္ဍ ၉ ခု (Core Modules)

### 1. ခြုံငုံသုံးသပ်ချက် စစ်ရေး/ငြိမ်းချမ်းရေး ဒက်ရှ်ဘုတ် (Executive Dashboard & KPIs)
- **ထိပ်တန်း ကိန်းဂဏန်းများ**: တိုင်းရင်းသားတပ်ဖွဲ့ ၂၅+ ဖွဲ့၊ တစ်နိုင်ငံလုံး စစ်ဘေးရှောင် ၃.၅+ သန်း၊ စိုးမိုးလွတ်မြောက်မြို့နယ် ၈၅+ မြို့နယ်၊ မူလ NCA ၁၀ ဖွဲ့၏ လက်ရှိအခြေအနေ။
- **ထိပ်တန်း Live Sitrep Ticker**: အရေးပေါ် အခြေအနေပြ Flashing Bulletin ဘားတန်း။
- **မဟာမိတ်အင်အားစု ၄ စု အချိုးအစား**:
  1. *ဖက်ဒရယ် တော်လှန်ရေး မဟာမိတ် (K3C + PDFs + BPLA)*: KNU, KIA, KNPP, CNF, ABSDF, BPLA, PDF
  2. *ညီနောင်မဟာမိတ် ၃ ဖွဲ့ (Three Brotherhood Alliance)*: AA, MNDAA, TNLA, DPLA, Chin Brotherhood
  3. *FPNCC နှင့် ကိုယ်ပိုင်အုပ်ချုပ်ခွင့်ရ ဒေသများ*: UWSA (ဝ), NDAA (မိုင်းလား), SSPP
  4. *NCA တွေ့ဆုံဆွေးနွေးဆဲနှင့် ဒေသန္တရအင်အားစုများ*: RCSS, DKBA, KNU/KNLA-PC, ALP, PNO, SNA

### 2. မြန်မာနိုင်ငံ ပြည်နယ်နှင့် တိုင်းများ အခြေအနေပြ စစ်ရေးမြေပုံ (Interactive Map)
- ပြည်နယ်နှင့် တိုင်း ၁၅ ခုကို **Interactive SVG Map** ဖြင့် ရေးဆွဲထားပြီး စစ်ရေးပြင်းထန်မှုအလိုက် အရောင်ခွဲခြား ပြသပေးသည်။
- **Layer Switcher**: 
  - *Conflict Heatmap (စစ်ရေးအပူမြေပုံ)*: ပြည်နယ်အလိုက် တိုက်ပွဲပြင်းထန်မှု။
  - *Battle Hotspots (တိုက်ပွဲဗဟိုချက်များ)*: လားရှိုး၊ လောက်ကိုင်၊ မိုးကုတ်၊ လွိုင်ကော်၊ သံတွဲ၊ မြဝတီ၊ လိုင်ဇာ အစရှိသော အဓိက စစ်ဆင်ရေးနေရာများတွင် Glowing Pin များဖြင့် ဖော်ပြထားပြီး နှိပ်၍ အသေးစိတ် စစ်ဆေးနိုင်ပါသည်။

### 3. မြို့နယ်များနှင့် နယ်မြေများ ထိန်းချုပ်မှု မက်ထရစ် (Townships Control Matrix)
- မြို့နယ်ပေါင်း ၈၅+ မြို့နယ်၏ လက်ရှိ အုပ်ချုပ်ရေးနှင့် စစ်ရေးအခြေအနေ-
  - **Liberated by Resistance (စိုးမိုးလွတ်မြောက်မြို့နယ်များ)**: လားရှိုး၊ လောက်ကိုင်၊ ချင်းရွှေဟော်၊ နမ့်ဆန်၊ ကျောက်မဲ၊ နောင်ချို၊ မိုးကုတ်၊ မြောက်ဦး၊ သံတွဲ၊ ပလက်ဝ၊ မတူပီ၊ ဒီးမော့ဆို၊ မယ်စဲ့ စသည်ဖြင့်
  - **Contested / Frontline (တိုက်ပွဲဖြစ်ပွားဆဲ မြို့များ)**: မြဝတီ၊ ဖာပွန်၊ ကောလင်း၊ ဆီဆိုင်
  - **SAC Junta Garrisons (စစ်ကောင်စီတပ်စွဲထားသော မြို့များ)**: စစ်တွေ၊ ကျောက်ဖြူ ရေနက်ဆိပ်ကမ်း
  - **Autonomous Zones (ကိုယ်ပိုင်အထူးဒေသများ)**: ပန်ဆန်း (ဝ အထူးဒေသ ၂)၊ မိုင်းလား (အထူးဒေသ ၄)
- ဒေသအလိုက်၊ အခြေအနေအလိုက် Instant Filter ပြုလုပ်နိုင်သလို စီမံခန့်ခွဲသူ၊ အခွန်ရငွေ၊ သယံဇာတ အရေးပါမှုတို့ကို ရှင်းလင်းစွာ ပြသပေးထားပါသည်။

### 4. အဆုံးအဖြတ် စစ်ဆင်ရေးကြီးများနှင့် ငြိမ်းချမ်းရေးဆွေးနွေးပွဲများ (Operations & Talks Tracker)
- **စစ်ဆင်ရေးကြီးများ**:
  - ၁၀၂၇ စစ်ဆင်ရေး (ပထမလှိုင်း) - ရှမ်းမြောက် စခန်း ၅၀၀ ကျော်နှင့် မြို့ ၁၆ မြို့ သိမ်းပိုက်မှု
  - ၁၀၂၇ စစ်ဆင်ရေး (ဒုတိယလှိုင်း) - လားရှိုး ရမခ တိုင်းစစ်ဌာနချုပ်နှင့် မိုးကုတ်၊ ကျောက်မဲ သိမ်းပိုက်မှု
  - ၁၁၁၁ စစ်ဆင်ရေး (လွိုင်ကော်တိုက်ပွဲနှင့် ကရင်နီပြည်နယ် ၈၀% လွတ်မြောက်မှု)
  - ၀၃၀၇ စစ်ဆင်ရေး (ကချင်ထိုးစစ်နှင့် လိုင်ဇာဌာနချုပ် လုံခြုံရေး၊ လွယ်ဂျယ်နယ်စပ်ဂိတ်)
  - မြဝတီတိုက်ပွဲနှင့် အာရှလမ်းမကြီး
- **ငြိမ်းချမ်းရေး တွေ့ဆုံဆွေးနွေးပွဲ အဆင့်ဆင့်**:
  - တရုတ်နိုင်ငံ ကူမင်းမြို့ ဟိုင်ဂင် အပစ်ရပ်ဆွေးနွေးပွဲ (Rounds 1 မှ 6 အထိ)
  - K3C ထိပ်သီးညီလာခံ ပူးတွဲနိုင်ငံရေး သဘောထားထုတ်ပြန်ချက်
  - အာဆီယံ အထူးကိုယ်စားလှယ် ခရီးစဉ်များ

### 5. တိုင်းရင်းသားလက်နက်ကိုင် အဖွဲ့များ မာတိကာ (EAO Directory - 25+ Organizations)
- KNU, KIA, AA, MNDAA, TNLA, UWSA, RCSS, KNPP, CNF, SSPP, PNLO, NMSP, NDAA, ABSDF, DKBA, KNA/BGF, **BPLA (မောင်ဆောင်းခ)**, **KNDF (ခွန်းဘီထူး)**, **PDF (NUG MOD)**, **Chin Brotherhood**, **PNO/PNA**, **SNA**, **DPLA (ဓနု)**, **ZRA** စသည့် အဖွဲ့ပေါင်း ၂၅+ ဖွဲ့၏ တပ်ဖွဲ့ခန့်မှန်းအင်အား၊ ဌာနချုပ်၊ NCA ရပ်တည်ချက်၊ ခေါင်းဆောင်များနှင့် အတွေးအခေါ်များကို ပြည့်စုံစွာ ဖော်ပြထားပါသည်။

### 6. သမိုင်းမှတ်တိုင်များ အချိန်မှတ်တမ်း (Peace Timeline: 1947 - 2026)
- ၁၉၄၇ ပင်လုံစာချုပ်မှ ၂၀၂၆ အထိ မြန်မာ့ငြိမ်းချမ်းရေးနှင့် စစ်ရေး အလှည့်အပြောင်း သမိုင်းမှတ်တိုင်အားလုံးကို ခေတ်ကာလအလိုက် စစ်ထုတ်ဖတ်ရှုနိုင်ပါသည်။

### 7. ငြိမ်းချမ်းရေး စာချုပ်စာတမ်းများ မော်ကွန်းတိုက် (Accords Archive)
- ပင်လုံစာချုပ် (၁၉၄၇)
- NCA တစ်နိုင်ငံလုံး အပစ်ရပ်စာချုပ် (၂၀၁၅) - အခန်း ၇ ခန်း အပြည့်အစုံ
- ဖက်ဒရယ်ဒီမိုကရေစီ ပဋိညာဉ် (၂၀၂၁)
- ဟိုင်ဂင် အပစ်ရပ် သဘောတူညီချက်များ (၂၀၂၄)
- အာဆီယံ ဘုံသဘောတူညီချက် ၅ ရပ်

### 8. မူဝါဒနှင့် သဘောထား ရှုထောင့်များ နှိုင်းယှဉ်ချက် (Stakeholder Matrix)
- ဖက်ဒရယ်တပ်မတော်၊ ဖွဲ့စည်းပုံအခြေခံဥပဒေ၊ သယံဇာတခွဲဝေမှု၊ တရားမျှတမှုဆိုင်ရာ ကိစ္စများတွင် SAC၊ NUG၊ EAOs နှင့် နိုင်ငံတကာ၏ မူဝါဒများကို ဘေးချင်းယှဉ် နှိုင်းယှဉ်ထားပါသည်။

### 9. စာရင်းအင်းနှင့် ခွဲခြမ်းစိတ်ဖြာမှု ဂရပ်များ (Analytics)
- တိုင်းနှင့် ပြည်နယ်အလိုက် စစ်ဘေးရှောင်ဦးရေ (IDPs) Bar Chart
- မဟာမိတ်အင်အားစုများ၏ တပ်ဖွဲ့ဝင်အချိုးအစားနှင့် Force Share Percentages

### 10. ဖက်ဒရယ်ဒီမိုကရေစီပြည်ထောင်စုပေါ်ထွန်းရေး ဦးဆောင်ကောင်စီ (SCEF Council)
- ၂၀၂၆ မတ်လ ၃၀ တွင် စတင်ဖွဲ့စည်းခဲ့သော အမြင့်ဆုံး မဟာမိတ်ဦးဆောင်မှုကောင်စီ အသေးစိတ်
- မဏ္ဍိုင် (၃) ရပ် (တိုင်းရင်းသားတော်လှန်ရေးအဖွဲ့များ၊ ပြည်သူ့ကိုယ်စားလှယ်များ၊ အမျိုးသမီးကဏ္ဍ)
- JMSCC ပူးတွဲစစ်မဟာဗျူဟာ ညှိနှိုင်းကွပ်ကဲရေး ကော်မတီနှင့် မူဝါဒလမ်းပြမြေပုံ ၆ ရပ်

### 11. လူသားချင်းစာနာမှုနှင့် စစ်ဘေးရှောင် အကျပ်အတည်း (Humanitarian & IDP Tracker)
- တစ်နိုင်ငံလုံး စစ်ဘေးရှောင် ၃.၅၅ သန်းကျော်၊ မီးရှို့ဖျက်ဆီးခံ နေအိမ် ၈၈,၀၀၀ ကျော်
- ထိုင်း၊ အိန္ဒိယ၊ တရုတ် နယ်စပ်ဖြတ်ကျော် ဒေသခံ CSO ကယ်ဆယ်ရေး လမ်းကြောင်းများ

### 12. နယ်စပ်ကုန်သွယ်ရေးဂိတ်များနှင့် ပထဝီစီးပွားရေး (Border Trade Matrix)
- မူဆယ်၊ ချင်းရွှေဟော်၊ မြဝတီ၊ ထီးခီး၊ ရိဒ်ခေါဒါရ်၊ မောင်တော အစရှိသော အဓိက နယ်စပ်ဂိတ် ၁၀ ခု
- တော်လှန်ရေးနှင့် တိုင်းရင်းသားအင်အားစုများ ၇၀% ကျော် ထိန်းချုပ်ထားမှုနှင့် အကောက်ခွန် ဝင်ငွေစီးဆင်းမှု

### 13. အောက်ခြေမှ တည်ဆောက်သော ဖက်ဒရယ် အုပ်ချုပ်ရေး (Bottom-up Federalism)
- ကရင်နီ (IEC)၊ ချင်းလဲန်း (Chinland Council)၊ အာရက္ခ (ULA/AA)၊ ကော်သူးလေ (KNU Districts) နှင့် “ဝ” (UWSA) တို့၏ တရားရုံး၊ ရဲတပ်ဖွဲ့၊ ပညာရေးနှင့် ကျန်းမာရေး စနစ်များ

### 14. လေကြောင်းတိုက်ခိုက်မှုနှင့် အရပ်သားထိခိုက်မှု (Air Strikes Monitor)
- စစ်ကောင်စီ၏ လေကြောင်းတိုက်ခိုက်မှု ၄,၈၅၀+ ကြိမ်၊ ဗုံးကြဲခံရသည့် စာသင်ကျောင်း ၂၄၆ ကျောင်း၊ ဆေးရုံ ၁၁၈ ရုံ
- တိုက်ခိုက်ရေး ဂျက်လေယာဉ်များစာရင်း (Su-30, MiG-29, FTC-2000G, Y-12, Mi-35) နှင့် လေယာဉ်ဆီ ပိတ်ဆို့ရေး အစီရင်ခံချက်

---

## ⚡ အထူးလုပ်ဆောင်ချက်များ (Special Features)

1. **မြေပုံ Time-Lapse Slider (၂၀၂၁ - ၂၀၂၆ အချိန်ခရီးသွားမြေပုံ)**:
   - စစ်အာဏာသိမ်းချိန်မှ လက်ရှိအချိန်အထိ နယ်မြေထိန်းချုပ်မှု ပြောင်းလဲလာပုံကို Play/Pause ဖြင့် မြေပုံပေါ်တွင် အချိန်နှင့်အမျှ ရွေ့လျားကြည့်ရှုနိုင်ခြင်း။
2. **Mobile View & Bottom Navigation Dock**:
   - စမတ်ဖုန်းများတွင် Native Mobile App ကဲ့သို့ အောက်ခြေ Bottom Dock ဖြင့် အဆင်ပြေချောမွေ့စွာ ကြည့်ရှုနိုင်ခြင်း။
3. **Executive SitRep Report (Print / PDF Export)**:
   - သံတမန်များ၊ သုတေသီများနှင့် မီဒီယာများအတွက် ကလစ်တစ်ချက်နှိပ်ရုံဖြင့် တရားဝင် Formal Situation Report ကို Print / PDF ထုတ်ယူနိုင်ခြင်း။
4. **Instant Global Quick Search (`Ctrl + K`)**:
   - မည်သည့်နေရာမှမဆို `Ctrl + K` နှိပ်၍ အဖွဲ့အစည်း၊ မြို့နယ်နှင့် စာချုပ်များကို ချက်ချင်း ရှာဖွေနိုင်ခြင်း။
5. **Bilingual (မြန်မာ / English)**:
   - ခလုတ်တစ်ချက်နှိပ်ရုံဖြင့် မြန်မာယူနီကုဒ်နှင့် အင်္ဂလိပ်ဘာသာ အပြည့်အဝ ပြောင်းလဲအသုံးပြုနိုင်ခြင်း။
